## <a name="features"></a>Возможности

Чем он отличается от других майнеров. Под каждым пунктом есть «Посмотреть в действии»:
там видно, как это работает.

### Аккаунты и стримеры

- **Несколько аккаунтов в одном приложении.** Каждый аккаунт майнит сам по себе, в своём
  режиме: **Drops и баллы** (один канал — для лучшей кампании, другой — для ваших
  стримеров), **Только Drops** или **Только баллы**.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/accounts-mining.avif" alt="Несколько аккаунтов майнят одновременно, на главной странице">
  </details>

- **Мастер для каждого нового аккаунта.** После входа начните с настроек по умолчанию или
  с настроек другого аккаунта. Выберите режим, кампании и стримеров, затем «Начать майнинг»
  или «Сохранить и запустить позже».

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/account-setup.avif" alt="Мастер настройки нового аккаунта, шаг за шагом">
  </details>

- **Одно изменение — на другие аккаунты в один клик.** Когда вы что-то меняете в аккаунте,
  сообщение с подтверждением предлагает «Применить к другим аккаунтам». То же изменение
  вносится в отмеченные аккаунты, а остальные их настройки не меняются.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/apply-to-accounts.avif" alt="Изменение, повторённое на других аккаунтах через «Применить к другим аккаунтам»">
  </details>

- **Добавление стримера.** Он сразу начинает работать с параметрами по умолчанию: заданными
  в приложении или выбранными вами для этого аккаунта. При необходимости поправьте их тут
  же: бонусные сундуки, рейды, моменты, серия просмотров, чат, прогнозы.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/streamer-add.avif" alt="Добавление стримера через поиск Twitch, затем его параметры">
  </details>

- **Изменение стримера.** «Изменить» открывает его параметры: бонусные сундуки, рейды,
  моменты, серия просмотров, чат, прогнозы… Переключатель включает или выключает его, не
  убирая из списка.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/streamer-edit.avif" alt="Параметры стримера, открытые из его строки">
  </details>

- **Изменение нескольких стримеров сразу.** Отметьте их, затем
  «Изменить N выбранных стримеров». Применяются только те параметры, которые вы меняете.
  Параметр, который у них различается, показывает «Разные», а его переключатель
  превращается в две кнопки: «Да» и «Нет». Затем приложение предлагает сделать эти
  параметры параметрами по умолчанию для новых стримеров.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/streamers-group-edit.avif" alt="Изменение нескольких стримеров с параметрами «Разные»">
  </details>

- **Импорт стримеров.** Вставьте список (до 500 имён) или возьмите список другого аккаунта
  либо каналы, которые отслеживает аккаунт. Список проверяется, так что добавляются только
  существующие каналы.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/streamers-import.avif" alt="Импорт стримеров: вставленный список, другой аккаунт, отслеживаемые каналы">
  </details>

- **Spam Points.** Обменивайте пользовательскую награду канала несколько раз подряд.
  Выберите канал из своего списка «Баллы» или любой канал, найденный через поиск Twitch:
  его награды показываются вместе с балансом аккаунта, который обновляется в реальном
  времени. Задайте количество (до 25, в пределах баланса), затем «Обменять». Результат
  появляется по завершении серии, а у каждой серии есть своя строка в Журнале.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/spam-points.avif" alt="Spam Points: выбор канала, 10 × обмен награды с сообщением, обмены появляются в чате канала на Twitch, затем строка в Журнале">
  </details>

### Drops

- **Все текущие кампании Drops.** У каждой кампании своя карточка: награды, привязка
  игрового аккаунта, «Майнить в первую очередь». Список берётся из проекта
  [Twitch Drops API](https://drops.sunkwi.com) и обновляется каждые 10 минут.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/drops-catalogue.avif" alt="Каталог в виде календаря, поиск и карточка кампании">
  </details>

- **Ваш порядок майнинга.** Перетащите кампании в нужном порядке. Новые сами встают на своё
  место: сначала ваши приоритетные игры, затем кампании, которые раньше заканчиваются или
  требуют меньше всего оставшихся минут. Исключайте игры, слова, кампанию или отдельную
  награду и пропускайте кампании, которые не успеют завершиться.
  «Майнить в первую очередь» в карточке кампании ставит её в начало.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/drops-order.avif" alt="Порядок майнинга, приоритетные игры и исключения">
  </details>

- **Инвентарь и «Получить все».** Страница «Инвентарь» раскладывает награды по группам
  «К получению», «В процессе» и «Получено». Получайте их по одной, все сразу или включите
  «Забирать drops автоматически».

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/drops-inventory.avif" alt="Инвентарь и кнопка «Получить все»">
  </details>

- **«Сначала мои стримеры для Drops».** Для текущей кампании стример из вашего списка, чей
  эфир засчитывается в эту кампанию, идёт раньше других каналов. Один и тот же канал
  продвигает дроп и приносит вам свои баллы канала. Включено по умолчанию.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/drops-streamers-first.avif" alt="Стример из списка, которого смотрят ради Drops и ради его баллов">
  </details>

- **Значки (бета).** Страница «Значки» показывает все глобальные значки чата Twitch и
  способы их получить. У каждого аккаунта своя страница «Значки»: значки в процессе с их
  прогрессом, те, что ещё можно получить, и те, что у него уже есть. Майнер берётся за
  значки, которым нужно только время просмотра, из кампаний Drops и квестов Twitch, и
  пропускает те, что у аккаунта уже есть. В «Что майнить и в каком порядке» расставьте
  перетаскиванием приоритетные игры, значки и другие кампании Drops в нужном порядке или
  отключите одну из групп. Эта функция в бета-версии.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/badges.avif" alt="Страница «Значки», значки одного аккаунта, затем «Что майнить и в каком порядке» со значками, перетащенными в начало">
  </details>

### Мониторинг

- **Журнал всего и каждый запрос.** Журнал хранит каждое событие: дропы, полученные
  и потраченные баллы, сундуки, ставки, рейды, начала эфиров… Фильтруйте его по аккаунту,
  вкладке (Drops, Баллы, Другое) и типу. **Технические логи › Запросы** показывает каждый
  запрос к Twitch и другим сервисам, с его результатом и длительностью. В логах и запросах
  нет ни токенов, ни секретов: «Скопировать для баг-репорта» копирует их в готовом для
  вставки виде, для баг-репорта на
  [GitHub](https://github.com/SunkwiBOT/twitch-miner/issues) или в
  [Discord](https://discord.gg/support-bots-891685895781113886).

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/journal-requests.avif" alt="Отфильтрованный Журнал, затем Технические логи › Запросы">
  </details>

### На компьютере или на сервере

- **Один и тот же интерфейс везде.** Десктопное приложение (Linux, Windows, macOS) и образ
  Docker показывают одну и ту же панель. Docker работает на VPS, NAS или Raspberry Pi, без
  экрана и браузера на этой машине: панель открывается в любом браузере.
  На телефоне панель подстраивается под экран, а по HTTPS устанавливается как приложение.
- **Лёгкий.** Около 30 МБ памяти на 4 аккаунта, почти нулевая нагрузка на процессор и образ
  Docker размером около 12 МБ.

### Безопасность и обновления

- **Ваши сессии под защитой.** Никакого пароля от Twitch: вы входите на
  `twitch.tv/activate` из своего браузера. Сессии хранятся на диске в зашифрованном виде,
  и их можно отозвать в [настройках Twitch](https://www.twitch.tv/settings/connections).
  На компьютере необязательный пароль приложения блокирует его: пока пароль не введён,
  ничего не майнится. В Docker у панели свой пароль, она сама блокируется после нескольких
  минут бездействия и работает по HTTPS за прокси. Пять неверных паролей подряд блокируют
  IP-адрес на 30 секунд.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/security-lock.avif" alt="Замок: приложение заблокировано, затем разблокировано паролем">
  </details>

- **Подписанные обновления, никогда не автоматические.** В верхней панели появляется значок
  «Обновление» с номером версии. «Установить и перезапустить» сначала просит
  подтверждения, затем приложение устанавливает версию и перезапускается. С паролем
  приложения оно перезапускается заблокированным: введите пароль снова, чтобы продолжить
  майнинг. Устанавливается только версия, подписанная проектом. Версия для Docker тоже
  сообщает об обновлении и показывает команды, которые нужно выполнить.

  <details open><summary>Посмотреть в действии</summary>
  <img src="../media/ru/updates.avif" alt="Значок «Обновление», подтверждение, затем установка">
  </details>

## <a name="docker"></a>Docker

Сервер показывает ту же панель в браузере. Образ —
`ghcr.io/sunkwibot/twitch-miner`, для `amd64` и `arm64`. Когда выходит
новая версия, панель сообщает об этом: `docker compose pull`, затем `docker compose up -d`.

```yaml
services:
  miner:
    image: ghcr.io/sunkwibot/twitch-miner:latest
    pull_policy: always   # при каждом запуске брать самый новый образ
    restart: unless-stopped
    ports: ["8080:8080"]   # за обратным HTTPS-прокси: удалите или замените на "127.0.0.1:8080:8080"
    environment:
      MINER_PASSWORD: "change-me"   # обязателен, не короче 12 символов
      # MINER_PUBLIC_URL: "https://miner.example.com"   # только за обратным HTTPS-прокси
    volumes:
      - miner-data:/data

volumes:
  miner-data:
```

```bash
docker compose up -d
```

Откройте <http://localhost:8080> (или адрес машины в вашей сети) и введите пароль.

### Переменные

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `MINER_PASSWORD` | нет | Пароль панели, обязателен: без него сервер отказывается запускаться. Не короче 12 символов (при более коротком пароле при запуске выводится предупреждение). Значение из примера `change-me` не принимается. |
| `MINER_PASSWORD_FILE` | нет | Читает `MINER_PASSWORD` из файла, например из секрета Docker. Задайте что-то одно, не оба сразу. |
| `MINER_PUBLIC_URL` | нет | Только за обратным HTTPS-прокси (Caddy, nginx, Traefik, Cloudflare Tunnel…): адрес `https://` панели, без пути, например `https://miner.example.com`. Прокси должен передавать `X-Forwarded-Proto`, `X-Forwarded-For` и веб-сокеты, что обычные прокси делают по умолчанию, а порт контейнера не должен быть доступен напрямую. Тогда панель отклоняет всё, что приходит не через прокси по HTTPS, и блокирует адрес на 30 секунд после 5 неверных паролей. Прокси должен работать на той же машине или в её локальной сети: подключение с публичного адреса отклоняется. |
| `MINER_TRUSTED_HOPS` | `1` | Только вместе с `MINER_PUBLIC_URL`: сколько прокси добавляют запись в `X-Forwarded-For`, от 1 до 10. `2`, если два прокси стоят один за другим, например Cloudflare перед Traefik. |
| `MINER_PROXY_NETWORKS` | нет | Только вместе с `MINER_PUBLIC_URL`: другие сети, из которых может подключаться прокси, кроме этой машины и её частной локальной сети, через запятую: один адрес или сеть вида `2001:db8:1::/64` — для локальной сети с глобальными адресами IPv6. |
| `MINER_VAULT_PASSPHRASE` | нет | Только для папки данных, скопированной из десктопного приложения с заданным паролем приложения: разблокирует её при запуске. Серверу, развёрнутому с нуля, она не нужна. |
| `MINER_VAULT_PASSPHRASE_FILE` | нет | Читает `MINER_VAULT_PASSPHRASE` из файла. Задайте что-то одно, не оба сразу. |
| `DATA_DIR` | `/data` в образе, иначе `data` в рабочем каталоге | База данных, файл ключа и логи. |
| `LOG_DIR` | `$DATA_DIR/logs` | Файлы логов: один в день, хранятся последние 14. |
| `HOST` / `PORT` | `0.0.0.0` / `8080` | Адрес прослушивания: IP-адрес и порт от 1 до 65535. |
| `RUST_LOG` | `info,hyper=warn,reqwest=warn` | Уровень логирования. |

Сервер читает и проверяет переменные один раз, при запуске. Недопустимое значение
останавливает сервер с сообщением, а не тихо заменяется запасным.

## <a name="how-it-works"></a>Как это работает

Каждые 20 секунд каждый аккаунт выбирает свои два канала: лучший канал в эфире для первой
кампании в его очереди, затем стримеров из его списка для баллов.

Twitch засчитывает на аккаунт одновременно **одну кампанию Drops** и
**два канала для баллов**. С октября 2026 года дроп можно получить, только если игровой
аккаунт привязан. Непривязанные кампании всё равно набирают прогресс, а панель показывает
ссылку для привязки.

Список кампаний берётся из проекта [Twitch Drops API](https://drops.sunkwi.com)
(обновляется каждые 10 минут), потому что Twitch скрывает его от клиента для ТВ.

## <a name="faq"></a>Частые вопросы

### Риски и Twitch

**Могут ли забанить мой аккаунт?**\
Никто не может гарантировать, что нет. Этот проект не связан с Twitch, а автоматизация
аккаунта может нарушать его правила или условия кампании. Майнер смотрит не больше двух
каналов на аккаунт — это ограничение Twitch — и не скачивает видео. Решать вам.

**Видео правда смотрится?**\
Нет, никакое видео не скачивается. Для Drops майнер каждые 15 секунд читает плейлист
стрима в самом низком качестве и запрашивает только заголовок каждого нового сегмента. Для
баллов он каждую минуту отправляет Twitch сигнал «минута просмотра». У каждого
просматриваемого канала видно, сколько сегментов было запрошено.

**Почему не больше двух каналов?**\
Это ограничение Twitch: он засчитывает на аккаунт только два канала, которые смотрятся
одновременно, и только одну кампанию Drops за раз. В режиме **Drops и баллы** один канал
работает на кампанию, а другой — на ваших стримеров. Настройка «Один канал» в разделе
**Настройки аккаунта** менее заметна.

### Drops

**Кампания не майнится или дроп не продвигается.**\
Откройте страницу **Drops** аккаунта. В блоке «Порядок майнинга» каждая ожидающая кампания
указывает причину: «Нет канала в эфире», «Ожидание (по одной кампании)» или
«Drop пока недоступен». Кампания, которой нет в этом списке, была отсеяна: настройкой
«Какие кампании», правилом на вкладке **Исключения** или потому, что она не успеет завершиться.
Награда, требующая подписки, никогда не майнится, а дроп, который идёт после другого, ждёт,
пока завершится первый. В режиме **Только баллы** майнер не выбирает кампаний.
«Майнить в первую очередь» в карточке кампании ставит её в начало; игнорируемую кампанию можно
вернуть кнопкой «Снова майнить» на вкладке **Исключения**.

**Нужно ли привязывать игровой аккаунт?**\
Чтобы получить награду — да: с октября 2026 года Twitch позволяет получить дроп, только
если игровой аккаунт привязан. По умолчанию непривязанная кампания всё равно продвигается,
а получение ждёт привязки. На это указывает значок «Не привязан», а
«Привязать игровой аккаунт» в карточке кампании открывает страницу привязки. Чтобы майнить
только привязанные игры, выберите «Только игры с привязанным аккаунтом».

### Установка и данные

**Десктопное приложение или Docker?**\
Десктопное приложение майнит, пока включён ваш ПК, со значком в трее, необязательным
паролем и обновлениями в один клик. Docker майнит круглосуточно на машине, которая всегда
включена (VPS, NAS, Raspberry Pi); вы открываете его в браузере, под защитой
`MINER_PASSWORD`. Интерфейс тот же.

**Где мои данные?**\
В папке данных: `~/.local/share/twitch-miner` в Linux,
`%APPDATA%\twitch-miner` в Windows,
`~/Library/Application Support/twitch-miner` в macOS и том `/data` в Docker.
На компьютере **Настройки › Рабочий стол** открывает её в один клик. В ней лежат
`miner.db` (аккаунты, настройки, журнал), `master.key` (ключ сессий, если пароль
приложения не задан) и логи.

**Как обновиться?**\
Десктопное приложение проверяет новую версию при запуске, а затем каждый час (это можно
изменить в разделе **Настройки › О программе**). Нажмите на значок «Обновление», затем на
«Установить и перезапустить». В Docker панель сообщает об обновлении: выполните
`docker compose pull`, затем `docker compose up -d`.

**Не помню пароль приложения.**\
Его нельзя восстановить: именно он шифрует ваши сессии Twitch. Закройте приложение,
удалите папку данных, затем снова добавьте аккаунты; их настройки придётся задать заново.
В Docker пароль панели меняется в `MINER_PASSWORD`, после чего выполняется
`docker compose up -d`.

### Баллы и прогнозы

**Сколько баллов в час?**\
Это зависит от Twitch и от конкретного канала. Майнер получает то же, что Twitch даёт
зрителю: баллы за просмотр, бонусные сундуки (примерно один раз в 15 минут) и бонус за
серию просмотров. Подписка умножает баллы — от ×1,2 до ×2 в зависимости от уровня. Главная
страница показывает полученные баллы, а Журнал — каждое начисление.

**Ставки — это рискованно?**\
Да, баллы можно потерять. Прогнозы по умолчанию выключены, для каждого стримера отдельно.
Вы задаёте стратегию, момент ставки, размер ставки (по умолчанию 5 % баланса, не больше
50 000 баллов), минимальный баланс и, если хотите, условие — например, коэффициент не ниже
1,5. Ставьте понемногу.

**Стример не смотрится.**\
Смотрятся только включённые стримеры в эфире, и только на свободном канале: в режиме
**Drops и баллы** один из двух занят текущей кампанией; в режиме **Только Drops** стримеры
не смотрятся; аккаунт на паузе не смотрит ничего. Места распределяются в таком порядке,
который показан значком на каждом просматриваемом канале: «Бонус за серию»,
«Серия под угрозой», «Подписка», затем «Порядок списка». Поднимите стримера выше в списке или
выключите «Сначала серии просмотров» и «Сначала каналы с подпиской».

## <a name="security"></a>Безопасность

- Токены шифруются с помощью AES-256-GCM. Ключ — это либо случайный `master.key` рядом
  с базой данных (по умолчанию, без участия пользователя), либо ключ, выведенный из пароля
  приложения с помощью Argon2id.
- HTTP-панель проверяет пароль за постоянное время и использует cookie с HttpOnly
  и SameSite=Strict (`Secure`, с префиксом `__Host-`, за HTTPS). Сервер хранит только хеш
  SHA-256 каждой сессии. Он завершает сессию через 30 дней или при выходе. Он проверяет
  сессию до чтения тела запроса и ограничивает тело 256 КиБ.
- После 5 неверных паролей подряд с одного IP-адреса (форма входа или bearer) этот адрес
  ждёт 30 секунд. Сервер отвечает `429` с `Retry-After`, даже не глядя на пароль. Кроме
  того, ответ на каждый неверный пароль приходит только через полсекунды.
- За пределами своей сети поставьте панель за обратный HTTPS-прокси с `MINER_PUBLIC_URL`
  (см. [Docker](#docker)).
- Майнер обращается только к `twitch.tv`, `ttvnw.net`, `jtvnw.net`, `twitchcdn.net`,
  `drops.sunkwi.com` и к настроенным вами адресатам уведомлений. Приложение
  (десктопное и Docker) проверяет новые версии на `github.com`, а десктопное приложение
  скачивает их из релизов проекта на GitHub. Они подписаны: устанавливается только
  показанная версия.

## <a name="build"></a>Сборка из исходного кода

**Что нужно:** Rust, Node.js и
[зависимости Tauri](https://v2.tauri.app/start/prerequisites/) для вашей системы.

```bash
npm ci
npm run build          # панель
cargo build --release -p miner-server   # сервер: target/release/twitch-miner
npm run bundle:linux   # десктопные пакеты (нужны Linux-зависимости Tauri)
```

Проверки кода:

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
npm run verify         # prettier, oxlint (с учётом типов) и svelte-check
```

Типы TypeScript для интерфейса генерируются из типов Rust с помощью
[ts-rs](https://github.com/Aleph-Alpha/ts-rs) в `ui/src/lib/bindings`. После изменения
типа, который видит интерфейс, выполните `npm run bindings`.
