## <a name="features"></a>ฟีเจอร์

สิ่งที่ทำให้แตกต่างจากตัวขุดอื่น กด “ดูการทำงานจริง” ใต้แต่ละข้อเพื่อดูว่าฟีเจอร์นั้นทำงานอย่างไร

### บัญชีและสตรีมเมอร์

- **หลายบัญชีในแอปเดียว** แต่ละบัญชีขุดแยกกันในโหมดของตัวเอง: **Drops และพอยต์** (ช่องหนึ่งสำหรับแคมเปญที่ดีที่สุด อีกช่องสำหรับสตรีมเมอร์ของคุณ) **Drops เท่านั้น** หรือ **พอยต์เท่านั้น**

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/accounts-mining.avif" alt="หลายบัญชีกำลังขุดพร้อมกันในหน้าแรก">
  </details>

- **ตัวช่วยตั้งค่าสำหรับทุกบัญชีใหม่** หลังเข้าสู่ระบบ จะเริ่มจากการตั้งค่าเริ่มต้นหรือจากการตั้งค่าของบัญชีอื่นก็ได้ เลือกโหมด แคมเปญ และสตรีมเมอร์ แล้วกด “เริ่มขุด” หรือ “บันทึกแล้วเริ่มภายหลัง”

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/account-setup.avif" alt="ตัวช่วยตั้งค่าบัญชีใหม่ทีละขั้นตอน">
  </details>

- **นำการเปลี่ยนแปลงไปใช้กับบัญชีอื่นได้ในคลิกเดียว** หลังคุณเปลี่ยนอะไรสักอย่างในบัญชีหนึ่ง ข้อความยืนยันจะเสนอ “นำไปใช้กับบัญชีอื่น” การเปลี่ยนแปลงนั้นจะถูกทำซ้ำในบัญชีที่คุณติ๊กไว้ ส่วนการตั้งค่าอื่นของบัญชีเหล่านั้นยังคงเดิม

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/apply-to-accounts.avif" alt="การเปลี่ยนแปลงที่ทำซ้ำในบัญชีอื่นด้วย “นำไปใช้กับบัญชีอื่น”">
  </details>

- **เพิ่มสตรีมเมอร์** สตรีมเมอร์เริ่มทำงานทันทีด้วยตัวเลือกเริ่มต้น ซึ่งเป็นของแอปหรือที่คุณเลือกไว้สำหรับบัญชีนี้ ปรับได้ทันทีหากจำเป็น: หีบโบนัส เรด โมเมนต์ สตรีคการดู แชท การทำนาย

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/streamer-add.avif" alt="เพิ่มสตรีมเมอร์ผ่านการค้นหาของ Twitch แล้วตามด้วยตัวเลือกของสตรีมเมอร์">
  </details>

- **แก้ไขสตรีมเมอร์** “แก้ไข” จะเปิดตัวเลือกของสตรีมเมอร์: หีบโบนัส เรด โมเมนต์ สตรีคการดู แชท การทำนาย… มีสวิตช์สำหรับเปิดหรือปิดสตรีมเมอร์โดยไม่ต้องลบออกจากรายการ

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/streamer-edit.avif" alt="ตัวเลือกของสตรีมเมอร์ที่เปิดจากแถวของสตรีมเมอร์คนนั้น">
  </details>

- **แก้ไขสตรีมเมอร์หลายคนพร้อมกัน** ติ๊กเลือกสตรีมเมอร์ แล้วกด “แก้ไขสตรีมเมอร์ที่เลือก N คน” ระบบจะใช้เฉพาะตัวเลือกที่คุณเปลี่ยน ตัวเลือกที่แต่ละคนตั้งไว้ไม่เหมือนกันจะแสดงเป็น “ผสม” และสวิตช์ของตัวเลือกนั้นจะกลายเป็นสองปุ่ม คือ “ใช่” และ “ไม่” จากนั้นแอปจะเสนอให้ตั้งเป็นตัวเลือกเริ่มต้นสำหรับสตรีมเมอร์ใหม่

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/streamers-group-edit.avif" alt="แก้ไขสตรีมเมอร์หลายคนพร้อมตัวเลือกที่เป็น “ผสม”">
  </details>

- **นำเข้าสตรีมเมอร์** วางรายชื่อ (สูงสุด 500 ชื่อ) หรือใช้รายการของบัญชีอื่น หรือใช้ช่องที่บัญชีนั้นติดตามอยู่ รายการจะถูกตรวจสอบเพื่อเพิ่มเฉพาะช่องที่มีอยู่จริง

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/streamers-import.avif" alt="นำเข้าสตรีมเมอร์: รายชื่อที่วาง บัญชีอื่น ช่องที่ติดตาม">
  </details>

- **Spam Points** แลกรางวัลที่กำหนดเองของช่องหลายครั้งติดกัน เลือกช่องจากรายการพอยต์ของคุณ หรือช่องใดก็ได้ที่พบผ่านการค้นหาของ Twitch: รางวัลของช่องจะแสดงพร้อมยอดคงเหลือของบัญชี ซึ่งอ่านใหม่แบบสด ตั้งจำนวน (สูงสุด 25 ครั้ง ไม่เกินยอดคงเหลือ) แล้วกด “แลก” ผลลัพธ์จะแสดงเมื่อการแลกชุดนั้นจบลง และแต่ละชุดจะมีบรรทัดของตัวเองในบันทึกกิจกรรม

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/spam-points.avif" alt="Spam Points: เลือกช่อง แลกรางวัลที่มีข้อความ 10 ครั้ง การแลกปรากฏในแชท Twitch ของช่อง แล้วตามด้วยบรรทัดในบันทึกกิจกรรม">
  </details>

### Drops

- **แคมเปญ Drops ทั้งหมดที่กำลังดำเนินอยู่** แต่ละแคมเปญมีรายละเอียดของตัวเอง: รางวัล การเชื่อมบัญชีเกม “ขุดก่อน” รายการนี้มาจากโปรเจกต์ [Twitch Drops API](https://drops.sunkwi.com) และรีเฟรชทุก 10 นาที

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/drops-catalogue.avif" alt="แคตตาล็อกแบบปฏิทิน การค้นหา และรายละเอียดของแคมเปญ">
  </details>

- **ลำดับการขุดของคุณเอง** ลากแคมเปญเรียงตามลำดับที่ต้องการ แคมเปญใหม่จะหาที่ของตัวเองได้: เกมที่คุณให้ความสำคัญมาก่อน ตามด้วยแคมเปญที่จะจบเร็วที่สุดหรือเหลือเวลาดูน้อยที่สุด ยกเว้นเกม คำ แคมเปญ หรือรางวัลเพียงชิ้นเดียวได้ และข้ามแคมเปญที่ทำไม่ทันเวลาได้ “ขุดก่อน” ในรายละเอียดของแคมเปญจะย้ายแคมเปญนั้นขึ้นไปไว้บนสุด

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/drops-order.avif" alt="ลำดับการขุด เกมที่ให้ความสำคัญ และการยกเว้น">
  </details>

- **คลังและ “รับทั้งหมด”** หน้าคลังแบ่งรางวัลเป็น “รอรับ” “กำลังดำเนินการ” และ “รับแล้ว” รับทีละชิ้น รับทั้งหมดในครั้งเดียว หรือเปิด “รับดรอปอัตโนมัติ”

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/drops-inventory.avif" alt="คลังและปุ่ม “รับทั้งหมด”">
  </details>

- **“สตรีมเมอร์ของฉันก่อนสำหรับ Drops”** สำหรับแคมเปญปัจจุบัน สตรีมเมอร์ในรายการของคุณที่สตรีมนับรวมในแคมเปญนั้นจะได้ดูก่อนช่องอื่น ช่องเดียวกันนี้ทั้งทำให้ดรอปคืบหน้าและได้พอยต์ช่องให้คุณ เปิดอยู่โดยค่าเริ่มต้น

  <details open><summary>ดูการทำงานจริง</summary>
  <img src="../media/th/drops-streamers-first.avif" alt="สตรีมเมอร์จากรายการที่ถูกดูทั้งเพื่อ Drops และเพื่อพอยต์">
  </details>

- **ตรา (เบต้า)** หน้าตราแสดงตราแชทส่วนกลางทั้งหมดของ Twitch และวิธีรับ แต่ละบัญชีมีหน้าตราของตัวเอง: ตราที่กำลังดำเนินการพร้อมความคืบหน้า ตราที่ยังรับได้ และตราที่มีอยู่แล้ว ตัวขุดจะไล่เก็บตราที่ใช้แค่เวลารับชม จากแคมเปญ Drops และเควสต์ของ Twitch และข้ามตราที่บัญชีมีอยู่แล้ว ใน “ขุดอะไรบ้าง ตามลำดับ” ลากเกมที่ให้ความสำคัญ ตรา และแคมเปญ Drops อื่น ๆ ไปเรียงตามลำดับที่ต้องการ หรือปิดอย่างใดอย่างหนึ่ง ฟีเจอร์นี้ยังเป็นเบต้า

  <details open><summary>ดูการทำงานจริง</summary>

  </details>

### บันทึกและตรวจสอบ

- **บันทึกทุกอย่าง และทุกคำขอ** บันทึกกิจกรรมเก็บทุกเหตุการณ์: ดรอป พอยต์ที่ได้และที่ใช้ไป หีบ การเดิมพัน เรด สตรีมที่เริ่มไลฟ์… กรองได้ตามบัญชี ตามแท็บ (Drops, พอยต์, อื่น ๆ) และตามประเภท **ล็อกทางเทคนิค › คำขอ** แสดงทุกคำขอที่ส่งไปยัง Twitch และบริการอื่น พร้อมผลลัพธ์และเวลาที่ใช้ ล็อกและคำขอไม่มีโทเค็นหรือข้อมูลลับใด ๆ: “คัดลอกสำหรับรายงานบั๊ก” จะคัดลอกไว้ให้ พร้อมวางในรายงานบั๊กบน [GitHub](https://github.com/SunkwiBOT/twitch-miner/issues) หรือ [Discord](https://discord.gg/support-bots-891685895781113886)

### บนเดสก์ท็อปหรือบนเซิร์ฟเวอร์

- **อินเทอร์เฟซเดียวกันทุกที่** แอปเดสก์ท็อป (Linux, Windows, macOS) และอิมเมจ Docker แสดงแดชบอร์ดเดียวกัน Docker รันบน VPS, NAS หรือ Raspberry Pi โดยเครื่องนั้นไม่ต้องมีหน้าจอหรือเบราว์เซอร์: แดชบอร์ดเปิดได้ในเบราว์เซอร์ใดก็ได้
  บนโทรศัพท์ แดชบอร์ดจะปรับให้พอดีกับหน้าจอ และเมื่อเปิดผ่าน HTTPS ก็ติดตั้งได้เหมือนแอป
- **เบา** ใช้หน่วยความจำราว 30 MB สำหรับ 4 บัญชี แทบไม่ใช้ CPU และอิมเมจ Docker มีขนาดราว 12 MB

### ความปลอดภัยและการอัปเดต

- **เซสชันของคุณได้รับการปกป้อง** ไม่ต้องใช้รหัสผ่าน Twitch: คุณเข้าสู่ระบบที่ `twitch.tv/activate` จากเบราว์เซอร์ของคุณ เซสชันถูกเข้ารหัสไว้บนดิสก์ และเพิกถอนได้ใน[การตั้งค่า Twitch](https://www.twitch.tv/settings/connections) ของคุณ บนเดสก์ท็อป รหัสผ่านแอปแบบไม่บังคับจะล็อกแอปไว้: จะไม่มีการขุดใด ๆ จนกว่าจะพิมพ์รหัสผ่าน เมื่อใช้ Docker แดชบอร์ดมีรหัสผ่านของตัวเอง ล็อกตัวเองเมื่อไม่มีการใช้งานไม่กี่นาที และทำงานผ่าน HTTPS หลัง proxy ใส่รหัสผ่านผิดห้าครั้งติดกันจะบล็อกที่อยู่ IP นั้นเป็นเวลา 30 วินาที

## <a name="docker"></a>Docker

เซิร์ฟเวอร์แสดงแดชบอร์ดเดียวกันในเบราว์เซอร์ อิมเมจคือ `ghcr.io/sunkwibot/twitch-miner` สำหรับ `amd64` และ `arm64` เมื่อมีเวอร์ชันใหม่ แดชบอร์ดจะแจ้งให้ทราบ: `docker compose pull` แล้วตามด้วย `docker compose up -d`

```yaml
services:
  miner:
    image: ghcr.io/sunkwibot/twitch-miner:latest
    pull_policy: always   # ดึงอิมเมจล่าสุดทุกครั้งที่เริ่ม
    restart: unless-stopped
    ports: ["8080:8080"]   # เมื่ออยู่หลัง HTTPS reverse proxy: ลบบรรทัดนี้ หรือใช้ "127.0.0.1:8080:8080"
    environment:
      MINER_PASSWORD: "change-me"   # จำเป็น ยาว 12 ตัวอักษรขึ้นไป
      # MINER_PUBLIC_URL: "https://miner.example.com"   # ใช้เฉพาะเมื่ออยู่หลัง HTTPS reverse proxy
    volumes:
      - miner-data:/data

volumes:
  miner-data:
```

```bash
docker compose up -d
```

เปิด <http://localhost:8080> (หรือที่อยู่ของเครื่องนั้นในเครือข่ายของคุณ) แล้วใส่รหัสผ่าน

### ตัวแปร

| ตัวแปร | ค่าเริ่มต้น | หน้าที่ |
|---|---|---|
| `MINER_PASSWORD` | ไม่มี | รหัสผ่านแดชบอร์ด จำเป็นต้องตั้ง: หากไม่มี เซิร์ฟเวอร์จะไม่ยอมเริ่มทำงาน ยาว 12 ตัวอักษรขึ้นไป (ถ้าสั้นกว่านี้ จะมีคำเตือนแสดงตอนเริ่ม) ค่าตัวอย่าง `change-me` จะถูกปฏิเสธ |
| `MINER_PASSWORD_FILE` | ไม่มี | อ่าน `MINER_PASSWORD` จากไฟล์ เช่น Docker secret ใช้อย่างใดอย่างหนึ่ง ไม่ใช่ทั้งสองอย่าง |
| `MINER_PUBLIC_URL` | ไม่มี | ใช้เฉพาะเมื่ออยู่หลัง HTTPS reverse proxy (Caddy, nginx, Traefik, Cloudflare Tunnel…): ที่อยู่ `https://` ของแดชบอร์ด โดยไม่มีพาธ เช่น `https://miner.example.com` proxy ต้องส่งต่อ `X-Forwarded-Proto`, `X-Forwarded-For` และ websocket ซึ่ง proxy ทั่วไปทำอยู่แล้วโดยค่าเริ่มต้น และต้องไม่มีใครเข้าถึงพอร์ตของคอนเทนเนอร์ได้โดยตรง จากนั้นแดชบอร์ดจะปฏิเสธทุกอย่างที่ไม่ได้มาทาง proxy ผ่าน HTTPS และจะล็อกที่อยู่หนึ่งเป็นเวลา 30 วินาทีหลังใส่รหัสผ่านผิด 5 ครั้ง พร็อกซีต้องทำงานบนเครื่องเดียวกันหรือในเครือข่ายภายในของเครื่องนั้น: การเชื่อมต่อจากที่อยู่สาธารณะจะถูกปฏิเสธ |
| `MINER_TRUSTED_HOPS` | `1` | ใช้คู่กับ `MINER_PUBLIC_URL` เท่านั้น: จำนวน proxy ที่เพิ่มรายการลงใน `X-Forwarded-For` ตั้งแต่ 1 ถึง 10 ใช้ `2` เมื่อมี proxy สองตัวซ้อนกัน เช่น Cloudflare อยู่หน้า Traefik |
| `MINER_PROXY_NETWORKS` | ไม่มี | ใช้ได้เฉพาะกับ `MINER_PUBLIC_URL`: เครือข่ายอื่นที่พร็อกซีเชื่อมต่อเข้ามาได้ นอกเหนือจากเครื่องนี้และเครือข่ายภายในส่วนตัวของมัน คั่นด้วยจุลภาค: ที่อยู่เดียวหรือเครือข่ายอย่าง `2001:db8:1::/64` สำหรับเครือข่ายภายในที่ใช้ที่อยู่ IPv6 แบบสาธารณะ |
| `MINER_VAULT_PASSPHRASE` | ไม่มี | ใช้เฉพาะกับโฟลเดอร์ข้อมูลที่คัดลอกมาจากแอปเดสก์ท็อปที่ตั้งรหัสผ่านแอปไว้: ใช้ปลดล็อกโฟลเดอร์นั้นตอนเริ่ม เซิร์ฟเวอร์ที่ตั้งขึ้นใหม่ตั้งแต่ต้นไม่จำเป็นต้องใช้ |
| `MINER_VAULT_PASSPHRASE_FILE` | ไม่มี | อ่าน `MINER_VAULT_PASSPHRASE` จากไฟล์ ใช้อย่างใดอย่างหนึ่ง ไม่ใช่ทั้งสองอย่าง |
| `DATA_DIR` | `/data` ในอิมเมจ นอกนั้นคือ `data` ในไดเรกทอรีทำงาน | ฐานข้อมูล ไฟล์คีย์ และล็อก |
| `LOG_DIR` | `$DATA_DIR/logs` | ไฟล์ล็อก: วันละหนึ่งไฟล์ เก็บไว้ 14 ไฟล์ล่าสุด |
| `HOST` / `PORT` | `0.0.0.0` / `8080` | ที่อยู่สำหรับรับการเชื่อมต่อ: ที่อยู่ IP และพอร์ตตั้งแต่ 1 ถึง 65535 |
| `RUST_LOG` | `info,hyper=warn,reqwest=warn` | ระดับล็อก |

เซิร์ฟเวอร์อ่านและตรวจสอบตัวแปรครั้งเดียวตอนเริ่ม ค่าที่ไม่ถูกต้องจะทำให้เซิร์ฟเวอร์หยุดพร้อมข้อความ แทนที่จะเงียบแล้วไปใช้ค่าสำรอง

## <a name="how-it-works"></a>วิธีการทำงาน

ทุก 20 วินาที แต่ละบัญชีจะเลือกสองช่องของตัวเอง: ช่องไลฟ์ที่ดีที่สุดสำหรับแคมเปญแรกในคิว แล้วจึงเป็นสตรีมเมอร์ในรายการพอยต์

Twitch นับ **แคมเปญ Drops หนึ่งแคมเปญ** และ **สองช่องสำหรับพอยต์** ต่อบัญชีในเวลาเดียวกัน ตั้งแต่เดือนตุลาคม 2026 ดรอปจะรับได้ก็ต่อเมื่อเชื่อมบัญชีเกมแล้วเท่านั้น แคมเปญที่ยังไม่เชื่อมยังคงคืบหน้าต่อ และแดชบอร์ดจะแสดงลิงก์สำหรับเชื่อม

รายการแคมเปญมาจากโปรเจกต์ [Twitch Drops API](https://drops.sunkwi.com) (รีเฟรชทุก 10 นาที) เพราะ Twitch ซ่อนรายการนี้จากไคลเอนต์ TV

## <a name="faq"></a>คำถามที่พบบ่อย

### ความเสี่ยงและ Twitch

**บัญชีของฉันอาจถูกแบนไหม?**\
ไม่มีใครรับประกันได้ว่าจะไม่โดน โปรเจกต์นี้ไม่มีส่วนเกี่ยวข้องกับ Twitch และการทำให้บัญชีทำงานอัตโนมัติอาจละเมิดข้อกำหนดของ Twitch หรือกติกาของแคมเปญ ตัวขุดดูได้ไม่เกินสองช่องต่อบัญชี ซึ่งเป็นข้อจำกัดของ Twitch และไม่ดาวน์โหลดวิดีโอใด ๆ การตัดสินใจเป็นของคุณ

**วิดีโอถูกดูจริงหรือเปล่า?**\
ไม่ ไม่มีการดาวน์โหลดวิดีโอใด ๆ สำหรับ Drops ตัวขุดจะอ่านเพลย์ลิสต์ของสตรีมที่คุณภาพต่ำสุดทุก 15 วินาที และขอเฉพาะส่วนหัวของแต่ละเซกเมนต์ใหม่ สำหรับพอยต์ จะส่งสัญญาณ “ดูไปแล้วหนึ่งนาที” ของ Twitch ทุกนาที แต่ละช่องที่ดูอยู่จะแสดงจำนวนเซกเมนต์ที่ขอไปแล้ว

**ทำไมดูได้ไม่เกินสองช่อง?**\
นั่นคือข้อจำกัดของ Twitch: Twitch นับเฉพาะสองช่องที่ดูพร้อมกันต่อบัญชี และนับแคมเปญ Drops ได้ทีละหนึ่งแคมเปญเท่านั้น ในโหมด **Drops และพอยต์** ช่องหนึ่งใช้กับแคมเปญ อีกช่องใช้กับสตรีมเมอร์ของคุณ การตั้งค่า “หนึ่งช่อง” ใน **การตั้งค่าบัญชี** จะเป็นที่สังเกตน้อยกว่า

### Drops

**แคมเปญไม่ถูกขุด หรือดรอปไม่คืบหน้า**\
เปิดหน้า **Drops** ของบัญชีนั้น ใน “ลำดับการขุด” แคมเปญที่รออยู่แต่ละรายการจะบอกเหตุผล: “ไม่มีช่องที่กำลังไลฟ์” “รอ (ทีละหนึ่งแคมเปญ)” หรือ “ยังไม่มีดรอปให้รับ” แคมเปญที่ไม่ปรากฏในรายการนั้นถูกคัดออกไปแล้ว: เพราะการตั้งค่า “แคมเปญไหนบ้าง” เพราะกฎในแท็บ **การยกเว้น** หรือเพราะทำไม่ทันเวลา รางวัลที่ต้องสมัครสมาชิกจะไม่ถูกขุดเลย และดรอปที่ต่อจากดรอปอื่นจะรอจนดรอปแรกเสร็จ ในโหมด **พอยต์เท่านั้น** ตัวขุดจะไม่เลือกแคมเปญใดเลย “ขุดก่อน” ในรายละเอียดของแคมเปญจะย้ายแคมเปญนั้นขึ้นไปไว้บนสุด ส่วนแคมเปญที่ละเว้นไว้กลับมาได้ด้วย “กลับมาขุด” ในแท็บ **การยกเว้น**

**ต้องเชื่อมบัญชีเกมไหม?**\
ถ้าจะรับดรอปก็ต้องเชื่อม: ตั้งแต่เดือนตุลาคม 2026 Twitch ให้รับดรอปได้ก็ต่อเมื่อเชื่อมบัญชีเกมแล้วเท่านั้น โดยค่าเริ่มต้น แคมเปญที่ยังไม่เชื่อมยังคงคืบหน้าต่อ และการรับจะรอจนกว่าจะเชื่อม ป้าย “ยังไม่เชื่อม” จะบอกสถานะนี้ และ “เชื่อมบัญชีเกม” ในรายละเอียดของแคมเปญจะเปิดหน้าสำหรับเชื่อมบัญชี หากต้องการขุดเฉพาะเกมที่เชื่อมแล้ว ให้เลือก “เฉพาะเกมที่เชื่อมบัญชีแล้ว”

### การติดตั้งและข้อมูล

**แอปเดสก์ท็อปหรือ Docker?**\
แอปเดสก์ท็อปขุดขณะที่ PC ของคุณเปิดอยู่ มีไอคอนในถาดระบบ รหัสผ่านแบบไม่บังคับ และอัปเดตได้ในคลิกเดียว Docker ขุดได้ทั้งวันทั้งคืนบนเครื่องที่เปิดอยู่ตลอด (VPS, NAS, Raspberry Pi) คุณเปิดผ่านเบราว์เซอร์ โดยมี `MINER_PASSWORD` ปกป้อง อินเทอร์เฟซเหมือนกัน

**ข้อมูลของฉันอยู่ที่ไหน?**\
อยู่ในโฟลเดอร์ข้อมูล: `~/.local/share/twitch-miner` บน Linux, `%APPDATA%\twitch-miner` บน Windows, `~/Library/Application Support/twitch-miner` บน macOS และวอลุ่ม `/data` เมื่อใช้ Docker บนเดสก์ท็อป **การตั้งค่า › เดสก์ท็อป** เปิดโฟลเดอร์นี้ได้ในคลิกเดียว ภายในมี `miner.db` (บัญชี การตั้งค่า บันทึกกิจกรรม) `master.key` (คีย์ของเซสชัน เมื่อไม่ได้ตั้งรหัสผ่านแอป) และล็อก

**อัปเดตอย่างไร?**\
แอปเดสก์ท็อปตรวจหาเวอร์ชันใหม่เมื่อเริ่มทำงาน จากนั้นทุกชั่วโมง (เปลี่ยนได้ใน **การตั้งค่า › เกี่ยวกับ**) คลิกป้าย “อัปเดต” แล้วกด “ติดตั้งและรีสตาร์ต” เมื่อใช้ Docker แดชบอร์ดจะแจ้งให้ทราบ: รัน `docker compose pull` แล้วตามด้วย `docker compose up -d`

**ฉันลืมรหัสผ่านแอป**\
กู้คืนไม่ได้: รหัสผ่านนี้คือสิ่งที่ใช้เข้ารหัสเซสชัน Twitch ของคุณ ปิดแอป ลบโฟลเดอร์ข้อมูล แล้วเพิ่มบัญชีของคุณใหม่ ซึ่งต้องตั้งค่าบัญชีเหล่านั้นใหม่ทั้งหมด เมื่อใช้ Docker ให้เปลี่ยนรหัสผ่านแดชบอร์ดใน `MINER_PASSWORD` แล้วรัน `docker compose up -d`

### พอยต์และการทำนาย

**ได้พอยต์ชั่วโมงละเท่าไร?**\
ขึ้นอยู่กับ Twitch และแต่ละช่อง ตัวขุดได้รับสิ่งที่ Twitch ให้ผู้ชมทั่วไป: พอยต์จากเวลาดู หีบโบนัส (ราวทุก 15 นาที) และโบนัสสตรีคการดู การสมัครสมาชิกจะคูณพอยต์ตั้งแต่ ×1.2 ถึง ×2 ตามระดับ หน้าแรกแสดงพอยต์ที่ได้ และบันทึกกิจกรรมแสดงการได้พอยต์แต่ละครั้ง

**การเดิมพันมีความเสี่ยงไหม?**\
มี พอยต์อาจเสียได้ การทำนายปิดอยู่โดยค่าเริ่มต้นสำหรับสตรีมเมอร์ทุกคน คุณกำหนดกลยุทธ์ จังหวะการเดิมพัน จำนวนเดิมพัน (ค่าเริ่มต้น 5% ของยอดคงเหลือ สูงสุด 50,000 พอยต์) ยอดคงเหลือขั้นต่ำ และหากต้องการ ก็กำหนดเงื่อนไขได้ เช่น อัตราต่อรองอย่างน้อย 1.5 ควรเดิมพันแต่น้อย

**สตรีมเมอร์ไม่ถูกดู**\
ระบบจะดูเฉพาะสตรีมเมอร์ที่เปิดไว้และกำลังไลฟ์ และดูได้เฉพาะในช่องที่ว่างอยู่: ในโหมด **Drops และพอยต์** หนึ่งในสองช่องใช้กับแคมเปญปัจจุบัน ในโหมด **Drops เท่านั้น** จะไม่ดูสตรีมเมอร์คนใดเลย บัญชีที่หยุดชั่วคราวจะไม่ดูอะไรเลย ช่องจะถูกจัดสรรตามลำดับนี้ ซึ่งแสดงเป็นป้ายบนแต่ละช่องที่ดูอยู่: “โบนัสสตรีค” “สตรีคใกล้ขาด” “สมัครสมาชิก” แล้วจึง “ลำดับในรายการ” ย้ายสตรีมเมอร์ขึ้นไปในรายการ หรือปิด “ให้ความสำคัญกับสตรีคการดู” และ “ช่องที่สมัครสมาชิกก่อน”

## <a name="security"></a>ความปลอดภัย

- โทเค็นถูกปิดผนึกด้วย AES-256-GCM คีย์เป็นได้ทั้ง `master.key` แบบสุ่มที่อยู่ข้างฐานข้อมูล (ค่าเริ่มต้น ไม่ต้องทำอะไร) หรือคีย์ที่ได้จากรหัสผ่านแอปด้วย Argon2id
- แดชบอร์ด HTTP ตรวจรหัสผ่านแบบใช้เวลาคงที่ และใช้คุกกี้ HttpOnly, SameSite=Strict (เมื่ออยู่หลัง HTTPS จะมี `Secure` และคำนำหน้า `__Host-`) เซิร์ฟเวอร์เก็บเพียง SHA-256 ของแต่ละเซสชัน เซสชันจะสิ้นสุดหลัง 30 วันหรือเมื่อออกจากระบบ เซิร์ฟเวอร์ตรวจเซสชันก่อนอ่านเนื้อหาคำขอใด ๆ และจำกัดเนื้อหาไว้ที่ 256 KiB
- หลังใส่รหัสผ่านผิด 5 ครั้งติดกันจากที่อยู่ IP เดียว (ฟอร์มเข้าสู่ระบบหรือ bearer) ที่อยู่นั้นต้องรอ 30 วินาที เซิร์ฟเวอร์ตอบ `429` พร้อม `Retry-After` โดยไม่ดูรหัสผ่าน รหัสผ่านที่ผิดแต่ละครั้งยังใช้เวลาครึ่งวินาทีกว่าจะได้คำตอบ
- เมื่อใช้งานนอกเครือข่ายของคุณ ให้วางแดชบอร์ดไว้หลัง HTTPS reverse proxy พร้อมตั้ง `MINER_PUBLIC_URL` (ดู [Docker](#docker))
- ตัวขุดติดต่อเฉพาะ `twitch.tv`, `ttvnw.net`, `jtvnw.net`, `twitchcdn.net`, `drops.sunkwi.com` และปลายทางการแจ้งเตือนที่คุณตั้งค่าไว้ แอป (เดสก์ท็อปและ Docker) ตรวจหาเวอร์ชันใหม่ที่ `github.com` และแอปเดสก์ท็อปดาวน์โหลดเวอร์ชันใหม่จาก GitHub releases ของโปรเจกต์ เวอร์ชันใหม่มีลายเซ็นกำกับ: จะติดตั้งเฉพาะเวอร์ชันที่แสดงเท่านั้น

## <a name="build"></a>บิลด์จากซอร์สโค้ด

**สิ่งที่ต้องมี:** Rust, Node.js และ[ข้อกำหนดเบื้องต้นของ Tauri](https://v2.tauri.app/start/prerequisites/)สำหรับระบบของคุณ

```bash
npm ci
npm run build          # แดชบอร์ด
cargo build --release -p miner-server   # เซิร์ฟเวอร์: target/release/twitch-miner
npm run bundle:linux   # แพ็กเกจเดสก์ท็อป (ต้องมี dependency ของ Tauri บน Linux)
```

ตรวจโค้ด:

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
npm run verify         # prettier, oxlint (แบบรู้ชนิดข้อมูล) และ svelte-check
```

ชนิดข้อมูล TypeScript ของอินเทอร์เฟซสร้างจากชนิดข้อมูล Rust ด้วย [ts-rs](https://github.com/Aleph-Alpha/ts-rs) ลงใน `ui/src/lib/bindings` หลังเปลี่ยนชนิดข้อมูลที่อินเทอร์เฟซใช้ ให้รัน `npm run bindings`
