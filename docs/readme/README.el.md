<h1 align="center">Twitch Miner</h1>

<p align="center">
  <strong>Εξορύσσει Twitch Drops, σήματα και πόντους καναλιού σε όσους λογαριασμούς θέλετε, χωρίς browser και χωρίς ανοιχτή καρτέλα του Twitch.</strong>
</p>

<p align="center">
  Εφαρμογή επιφάνειας εργασίας για Linux, Windows και macOS ή εικόνα Docker με τον ίδιο web πίνακα ελέγχου, για εκτέλεση σε οικιακό server ή σε Raspberry Pi. Κάθε λογαριασμός χρησιμοποιεί περίπου 3 MB μνήμης και σχεδόν καθόλου CPU.
</p>

Κατεβάστε το αρχείο για το σύστημά σας από την [τελευταία έκδοση](https://github.com/SunkwiBOT/twitch-miner/releases/latest).

| **macOS** 13 ή νεότερο · universal: Intel και Apple Silicon | [Εικόνα δίσκου](https://github.com/SunkwiBOT/twitch-miner/releases/latest/download/twitch-miner_macos_universal.dmg) (`.dmg`) |

| **Linux server** · x86-64 ή ARM64 | Μόνο ο server, χωρίς Docker ([x86-64](https://github.com/SunkwiBOT/twitch-miner/releases/latest/download/twitch-miner-server_linux_x64) ή [ARM64](https://github.com/SunkwiBOT/twitch-miner/releases/latest/download/twitch-miner-server_linux_arm64)): δείτε [Χωρίς Docker](#systemd) |

Σε Linux μπορείτε επίσης να κάνετε εγκατάσταση από τερματικό. Σε ARM64, αντικαταστήστε το `x64` με `arm64` στις εντολές.

Debian, Ubuntu, Raspberry Pi OS:

```bash
curl -LO https://github.com/SunkwiBOT/twitch-miner/releases/latest/download/twitch-miner_linux_x64.deb
sudo apt install ./twitch-miner_linux_x64.deb
```

Fedora, openSUSE:

```bash
curl -LO https://github.com/SunkwiBOT/twitch-miner/releases/latest/download/twitch-miner_linux_x64.rpm
sudo dnf install ./twitch-miner_linux_x64.rpm
# openSUSE: sudo zypper install ./twitch-miner_linux_x64.rpm
```

AppImage, σε οποιαδήποτε διανομή:

```bash
curl -LO https://github.com/SunkwiBOT/twitch-miner/releases/latest/download/twitch-miner_linux_x64.AppImage
chmod +x twitch-miner_linux_x64.AppImage
./twitch-miner_linux_x64.AppImage
```

Οι ίδιες εντολές ενημερώνουν μια υπάρχουσα εγκατάσταση: τα ονόματα των αρχείων δεν αλλάζουν.

Η έκδοση για macOS δεν έχει περάσει notarization. Την πρώτη φορά, ανοίξτε την εφαρμογή: το macOS τη μπλοκάρει. Μετά πηγαίνετε στις **Ρυθμίσεις συστήματος › Απόρρητο και ασφάλεια** και κάντε κλικ στο **Άνοιγμα οπωσδήποτε**.

Οι ενημερώσεις είναι υπογεγραμμένες. Η εφαρμογή ελέγχει για νέα έκδοση κατά την εκκίνηση και μετά κάθε ώρα (τη συχνότητα την αλλάζετε από τις **Ρυθμίσεις › Σχετικά**). Δεν εγκαθιστά ποτέ μόνη της μια έκδοση: την εγκαθιστάτε εσείς με ένα κλικ, από το μήνυμα που εμφανίζεται ή από τις **Ρυθμίσεις › Σχετικά**.

Τα δεδομένα βρίσκονται στον φάκελο δεδομένων του χρήστη:

- Linux: `~/.local/share/twitch-miner`
- Windows: `%APPDATA%\twitch-miner`
- macOS: `~/Library/Application Support/twitch-miner`

## <a name="features"></a>Λειτουργίες

### Λογαριασμοί και streamers

- **Όσοι λογαριασμοί θέλετε σε μία εφαρμογή.** Κάθε λογαριασμός εξορύσσει ανεξάρτητα, στη δική του λειτουργία: **Drops και πόντοι** (ένα κανάλι για την καλύτερη καμπάνια, το άλλο για τους streamers σας), **Μόνο Drops** ή **Μόνο πόντοι**.

  <img src="../media/el/accounts-mining.avif" alt="Πολλοί λογαριασμοί κάνουν εξόρυξη ταυτόχρονα, στην Αρχική">

- **Οδηγός για κάθε νέο λογαριασμό.** Μετά τη σύνδεση, ξεκινήστε από τις προεπιλεγμένες ρυθμίσεις ή από τις ρυθμίσεις ενός άλλου λογαριασμού. Επιλέξτε τη λειτουργία, τις καμπάνιες και τους streamers και μετά «Έναρξη εξόρυξης» ή «Αποθήκευση και έναρξη αργότερα».

  <img src="../media/el/account-setup.avif" alt="Ο οδηγός ρύθμισης ενός νέου λογαριασμού, βήμα βήμα">

- **Μια αλλαγή περνά σε άλλους λογαριασμούς με ένα κλικ.** Αφού αλλάξετε κάτι σε έναν λογαριασμό, το μήνυμα επιβεβαίωσης προτείνει «Εφαρμογή σε άλλους λογαριασμούς». Η αλλαγή γίνεται ξανά στους λογαριασμούς που επιλέγετε, οι οποίοι κρατούν τις υπόλοιπες ρυθμίσεις τους.

  <img src="../media/el/apply-to-accounts.avif" alt="Μια αλλαγή που γίνεται ξανά σε άλλους λογαριασμούς με την «Εφαρμογή σε άλλους λογαριασμούς»">

- **Προσθήκη streamer.** Ξεκινά αμέσως με τις προεπιλεγμένες επιλογές: της εφαρμογής ή αυτές που διαλέξατε για αυτόν τον λογαριασμό. Προσαρμόστε τες επιτόπου αν χρειάζεται: μπόνους σεντούκια, raids, στιγμές, σερί παρακολούθησης, συνομιλία, προβλέψεις.

  <img src="../media/el/streamer-add.avif" alt="Προσθήκη streamer μέσω της αναζήτησης του Twitch και μετά οι επιλογές του">

- **Επεξεργασία streamer.** Η «Επεξεργασία» ανοίγει τις επιλογές του: μπόνους σεντούκια, raids, στιγμές, σερί παρακολούθησης, συνομιλία, προβλέψεις… Ένας διακόπτης τον ενεργοποιεί ή τον απενεργοποιεί χωρίς να τον αφαιρεί από τη λίστα.

  <img src="../media/el/streamer-edit.avif" alt="Οι επιλογές ενός streamer, ανοιγμένες από τη γραμμή του">

- **Επεξεργασία πολλών streamers μαζί.** Επιλέξτε τους και μετά «Επεξεργασία των N επιλεγμένων streamers». Εφαρμόζονται μόνο οι επιλογές που αλλάζετε. Μια επιλογή που διαφέρει ανάμεσά τους εμφανίζεται ως «Μικτό» και ο διακόπτης της γίνεται δύο κουμπιά, «Ναι» και «Όχι». Στη συνέχεια η εφαρμογή προτείνει να γίνουν αυτές οι προεπιλεγμένες επιλογές για τους νέους streamers.

  <img src="../media/el/streamers-group-edit.avif" alt="Επεξεργασία πολλών streamers, με επιλογές «Μικτό»">

- **Εισαγωγή streamers.** Επικολλήστε μια λίστα (έως 500 ονόματα) ή πάρτε τη λίστα ενός άλλου λογαριασμού ή τα κανάλια που ακολουθεί ο λογαριασμός. Η λίστα ελέγχεται, ώστε να προστίθενται μόνο κανάλια που υπάρχουν. Οι ζωντανές ενημερώσεις καλύπτουν 46 streamers ανά λογαριασμό: οι επόμενοι της λίστας δεν παίρνουν raids, στιγμές ούτε προβλέψεις.

  <img src="../media/el/streamers-import.avif" alt="Εισαγωγή streamers: επικολλημένη λίστα, άλλος λογαριασμός, κανάλια που ακολουθούνται">

- **Spam Points.** Εξαργυρώστε μια προσαρμοσμένη ανταμοιβή ενός καναλιού πολλές φορές στη σειρά. Επιλέξτε ένα κανάλι από τη λίστα Πόντων σας ή οποιοδήποτε κανάλι βρείτε με την αναζήτηση του Twitch: οι ανταμοιβές του εμφανίζονται με το υπόλοιπο του λογαριασμού, που διαβάζεται ξανά ζωντανά. Ορίστε την ποσότητα (έως 25, εντός του υπολοίπου) και μετά «Εξαργύρωση». Το αποτέλεσμα εμφανίζεται όταν τελειώσει η σειρά, και κάθε σειρά έχει τη δική της γραμμή στο Χρονικό.

  <img src="../media/el/spam-points.avif" alt="Spam Points: επιλογή καναλιού, εξαργύρωση 10 × μιας ανταμοιβής με μήνυμα, οι εξαργυρώσεις εμφανίζονται στη συνομιλία Twitch του καναλιού και μετά η γραμμή στο Χρονικό">

### Drops

- **Όλες οι ενεργές καμπάνιες Drops.** Κάθε καμπάνια έχει τις δικές της λεπτομέρειες: ανταμοιβές, σύνδεση λογαριασμού εκδότη, «Εξόρυξη με προτεραιότητα». Η λίστα προέρχεται από το έργο [Twitch Drops API](https://drops.sunkwi.com) και ανανεώνεται κάθε 5 λεπτά.

  <img src="../media/el/drops-catalogue.avif" alt="Ο Κατάλογος ως ημερολόγιο, η αναζήτηση και οι λεπτομέρειες μιας καμπάνιας">

- **Η δική σας σειρά εξόρυξης.** Σύρετε τις καμπάνιες στη σειρά που θέλετε. Οι νέες βρίσκουν μόνες τους τη θέση τους: πρώτα οι κατηγορίες προτεραιότητάς σας, μετά όσες λήγουν νωρίτερα ή όσες χρειάζονται τα λιγότερα λεπτά. Εξαιρέστε κατηγορίες, λέξεις, μια καμπάνια ή μία μόνο ανταμοιβή και παραλείψτε τις καμπάνιες που δεν προλαβαίνουν να ολοκληρωθούν. Η «Εξόρυξη με προτεραιότητα», στις λεπτομέρειες μιας καμπάνιας, τη βάζει στην κορυφή.

  <img src="../media/el/drops-order.avif" alt="Η σειρά εξόρυξης, οι κατηγορίες προτεραιότητας και οι εξαιρέσεις">

- **Απόθεμα και «Παραλαβή όλων».** Η σελίδα Απόθεμα χωρίζει τις ανταμοιβές σε «Προς παραλαβή», «Σε εξέλιξη» και «Παραλήφθηκαν». Παραλάβετέ τες μία μία, όλες μαζί ή ενεργοποιήστε την «Αυτόματη παραλαβή drops». Μετά το «Σύνδεση λογαριασμού εκδότη», ο λογαριασμός διαβάζεται ξανά μόλις επιστρέψετε στην εφαρμογή, ώστε η σύνδεση να φαίνεται αμέσως.

  <img src="../media/el/drops-inventory.avif" alt="Το απόθεμα και το κουμπί «Παραλαβή όλων»">

- **«Πρώτα οι streamers μου για Drops και σήματα».** Για την τρέχουσα καμπάνια, ένας streamer της λίστας σας του οποίου το stream μετράει για αυτή την καμπάνια προηγείται των άλλων καναλιών. Το ίδιο κανάλι προωθεί το drop και σας αποφέρει τους πόντους καναλιού του. Ενεργό από προεπιλογή.

  <img src="../media/el/drops-streamers-first.avif" alt="Ένας streamer της λίστας, που παρακολουθείται για τα Drops και για τους πόντους του">

- **Προτεραιότητα ανταμοιβών.** Όταν δύο καμπάνιες έχουν την ίδια κατάταξη, ο miner επιλέγει πρώτα εκείνη της οποίας οι ανταμοιβές ταιριάζουν στο είδος που προτιμάτε (σήμα, emote, αντικείμενο παιχνιδιού). Δεν παρακάμπτει ποτέ τη σειρά εξόρυξής σας.

- **Σήματα (beta).** Η σελίδα Σήματα παραθέτει όλα τα καθολικά σήματα συνομιλίας του Twitch και πώς αποκτώνται. Κάθε λογαριασμός έχει τη δική του σελίδα Σήματα: τα σήματα σε εξέλιξη με την πρόοδό τους, όσα μπορεί ακόμη να αποκτήσει και όσα κατέχει. Ο miner κυνηγά τα σήματα των καμπανιών Drops και των αποστολών του Twitch και παραλείπει όσα έχει ήδη ο λογαριασμός. Ένα σήμα που θέλει παρακολούθηση κάθε μέρα εξορύσσεται ξανά κάθε μέρα ως την τελευταία («20 λ. την ημέρα, 3 ημέρες»), και μετρά ένα κανάλι από οποιαδήποτε κατηγορία της καμπάνιας. Ένα σεντούκι δίνει «1 τυχαίο σήμα από N». Ένα σήμα που απαιτεί συνδρομή εξορύσσεται όταν έχετε κάνει ή έχετε χαρίσει μια συνδρομή κατά τη διάρκεια της καμπάνιας, σε ένα κανάλι της κατηγορίας, και το Twitch την έχει μετρήσει. Μια ήδη ενεργή συνδρομή, μια συνδρομή Prime ή μια ανανέωση δεν μετράνε. Τίποτα δεν εξορύσσεται πριν ξεκινήσει η καμπάνια του. Στο «Τι να εξορύσσεται, με σειρά», σύρετε τις κατηγορίες προτεραιότητας, τα σήματα και τις άλλες καμπάνιες Drops στη σειρά που θέλετε ή απενεργοποιήστε κάποιο από αυτά. Μια αποστολή του Twitch εξορύσσεται μόνο σε κανάλι όπου το Twitch την προσφέρει στον πίνακα Drops του. Μια εξέλιξη (Pichu → Pikachu) εξορύσσεται μόλις ο λογαριασμός έχει το σήμα από το οποίο προέρχεται: ο miner φοράει μόνος του αυτό το σήμα λίγο πριν και δεν ξαναβάζει το παλιό· το «Εξόρυξη εξελίξεων σημάτων», στις ρυθμίσεις σημάτων του λογαριασμού, το απενεργοποιεί. Ένα κλικ σε ένα σήμα ανοίγει τις λεπτομέρειές του: ολόκληρη την απαίτηση, όλες τις κατηγορίες και τα κανάλια, τη συλλογή, την εξέλιξη και την πρόοδο κάθε λογαριασμού. Αυτή η λειτουργία είναι σε beta.

  <img src="../media/el/badges.avif" alt="Η σελίδα Σήματα, τα σήματα ενός λογαριασμού και μετά το «Τι να εξορύσσεται, με σειρά» με τα Σήματα συρμένα πρώτα">

### Παρακολούθηση δραστηριότητας

- **Χρονικό για όλα και κάθε αίτημα.** Το Χρονικό κρατά κάθε συμβάν: drops, πόντους που κερδήθηκαν και ξοδεύτηκαν, σεντούκια, στοιχήματα, raids, streams που ξεκινούν… Φιλτράρετέ το ανά λογαριασμό, ανά καρτέλα (Drops, Σήματα, Πόντοι, Άλλα) και ανά τύπο. Τα **Αρχεία καταγραφής › Αιτήματα** δείχνουν κάθε αίτημα που στάλθηκε στο Twitch και σε άλλες υπηρεσίες, με το αποτέλεσμά του και τη διάρκειά του. Τα αρχεία καταγραφής και τα αιτήματα δεν περιέχουν κανένα token ή μυστικό: η «Αντιγραφή για αναφορά σφάλματος» τα αντιγράφει, έτοιμα για επικόλληση σε μια αναφορά σφάλματος στο [GitHub](https://github.com/SunkwiBOT/twitch-miner/issues) ή στο [Discord](https://discord.gg/support-bots-891685895781113886).

  <img src="../media/el/journal-requests.avif" alt="Το φιλτραρισμένο Χρονικό και μετά τα Αρχεία καταγραφής › Αιτήματα">

- **Μια σελίδα Στατιστικά.** Πόντοι που κερδήθηκαν, drops που παραλήφθηκαν, χρόνος
  παρακολούθησης και προβλέψεις που κερδήθηκαν σε 7, 30 ή 90 ημέρες, με τον κορυφαίο
  streamer ή την κορυφαία κατηγορία πίσω από κάθε νούμερο. Μια καμπύλη πόντων ανά
  streamer δείχνει το υπόλοιπο στον χρόνο, με δείκτες για σερί παρακολούθησης, raids,
  στιγμές και προβλέψεις και μια επεξήγηση σε καθεμία.

  <img src="../media/el/stats.avif" alt="Τα πλακίδια Στατιστικά για 30 ημέρες, μετά η καμπύλη πόντων ενός streamer με έναν δείκτη">

- **Παύση και ημερήσια παύση.** Ένα κουμπί παύσης, για έναν λογαριασμό ή για όλους: παύση μέχρι να συνεχίσετε, ή για 30 λεπτά, 1 ώρα, 4 ώρες, έως αύριο στις 09:00, ή έως μια προσαρμοσμένη ημερομηνία και ώρα· όσο είναι σε παύση, το ίδιο κουμπί γράφει «Συνέχεια». Ένα σήμα δείχνει πότε τελειώνει μια χρονικά οριοθετημένη παύση και κάθε λογαριασμός στην πλαϊνή στήλη δείχνει την κατάστασή του: εκτελείται, σε παύση ή πρόβλημα που θέλει προσοχή. Μια ημερήσια παύση σταματά την εξόρυξη σε όλους τους λογαριασμούς κάθε μέρα ανάμεσα σε δύο ώρες, στη ζώνη ώρας που επιλέγετε, και τη συνεχίζει όταν τελειώσει, με δικό της σήμα στην επάνω γραμμή.
- **Εξαγωγή CSV και αριθμός ανά κατηγορία.** Το Χρονικό εξάγει τα drops που παραλήφθηκαν ως αρχείο CSV (ημερομηνία, λογαριασμός, κατηγορία, καμπάνια, drop, λεπτά), φιλτραρισμένα ανά λογαριασμό, και ένα παράθυρο διαλόγου παραθέτει πόσα drops παραλήφθηκαν σε κάθε κατηγορία. Η εφαρμογή επιφάνειας εργασίας αποθηκεύει το αρχείο μέσω παραθύρου αποθήκευσης· ο πίνακας ελέγχου web το κατεβάζει.

### Στην επιφάνεια εργασίας ή σε server

- **Το ίδιο περιβάλλον παντού.** Η εφαρμογή επιφάνειας εργασίας (Linux, Windows, macOS) και η εικόνα Docker εμφανίζουν τον ίδιο πίνακα ελέγχου. Το Docker τρέχει σε VPS, NAS ή Raspberry Pi, χωρίς οθόνη ή browser σε εκείνο το μηχάνημα: ο πίνακας ελέγχου ανοίγει σε οποιονδήποτε browser.
  Στο κινητό ο πίνακας ελέγχου προσαρμόζεται στην οθόνη και, μέσω HTTPS, εγκαθίσταται σαν εφαρμογή.
- **Ελαφρύ.** Περίπου 3 MB μνήμης ανά λογαριασμό, σχεδόν καθόλου CPU και μια εικόνα Docker περίπου 12 MB.

### Ασφάλεια και ενημερώσεις

- **Οι συνεδρίες σας, προστατευμένες.** Κανένας κωδικός Twitch: συνδέεστε στο `twitch.tv/activate`, από τον browser σας. Οι συνεδρίες είναι κρυπτογραφημένες στον δίσκο και μπορείτε να τις ανακαλέσετε από τις [ρυθμίσεις του Twitch](https://www.twitch.tv/settings/connections). Στην επιφάνεια εργασίας, ένας προαιρετικός κωδικός εφαρμογής κλειδώνει την εφαρμογή: τίποτα δεν εξορύσσεται μέχρι να πληκτρολογηθεί. Με το Docker, ο πίνακας ελέγχου έχει τον δικό του κωδικό, κλειδώνει μόνος του μετά από λίγα λεπτά αδράνειας και λειτουργεί μέσω HTTPS πίσω από proxy. Πέντε λάθος κωδικοί στη σειρά μπλοκάρουν τη διεύθυνση IP για 30 δευτερόλεπτα.

- **Υπογεγραμμένες ενημερώσεις, ποτέ αυτόματες.** Ένα σήμα «Ενημέρωση» με τον αριθμό της έκδοσης εμφανίζεται στην πάνω γραμμή, και μια ειδοποίηση επιφάνειας εργασίας σάς το λέει κι αυτή, ενεργή από προεπιλογή (ένας διακόπτης στις **Ρυθμίσεις › Ειδοποιήσεις** την απενεργοποιεί· σε browser, πατήστε «Να επιτρέπονται» όταν σας ρωτήσει). Η «Εγκατάσταση και επανεκκίνηση» ζητά πρώτα επιβεβαίωση και μετά η εφαρμογή εγκαθιστά την έκδοση και επανεκκινείται. Αν έχετε κωδικό εφαρμογής, επανεκκινείται κλειδωμένη: πληκτρολογήστε τον ξανά για να συνεχιστεί η εξόρυξη. Εγκαθίσταται μόνο έκδοση υπογεγραμμένη από το έργο. Ο πίνακας ελέγχου του Docker και το δυαδικό αρχείο systemd σάς ειδοποιούν επίσης, με τις εντολές που πρέπει να εκτελέσετε.

## <a name="docker"></a>Docker

Ο server εμφανίζει τον ίδιο πίνακα ελέγχου σε browser. Η εικόνα είναι η `ghcr.io/sunkwibot/twitch-miner`, για `amd64` και `arm64`. Όταν βγαίνει νέα έκδοση, ο πίνακας ελέγχου σάς το λέει: `docker compose pull` και μετά `docker compose up -d`.

```yaml
services:
  miner:
    image: ghcr.io/sunkwibot/twitch-miner:latest
    pull_policy: always   # παίρνει την πιο πρόσφατη εικόνα σε κάθε εκκίνηση
    restart: unless-stopped
    ports: ["8080:8080"]   # πίσω από HTTPS reverse proxy: αφαιρέστε το ή βάλτε "127.0.0.1:8080:8080"
    environment:
      MINER_PASSWORD: "change-me"   # υποχρεωτικός, 12 χαρακτήρες ή περισσότεροι
      # MINER_PUBLIC_URL: "https://miner.example.com"   # μόνο πίσω από HTTPS reverse proxy
    volumes:
      - miner-data:/data

volumes:
  miner-data:
```

```bash
docker compose up -d
```

Ανοίξτε το <http://localhost:8080> (ή τη διεύθυνση του μηχανήματος στο δίκτυό σας) και εισαγάγετε τον κωδικό.

### Μεταβλητές

| Μεταβλητή | Προεπιλογή | Σκοπός |
|---|---|---|
| `MINER_PASSWORD` | καμία | Κωδικός του πίνακα ελέγχου, υποχρεωτικός: χωρίς αυτόν ο server αρνείται να ξεκινήσει. 12 χαρακτήρες ή περισσότεροι (με πιο σύντομο εμφανίζεται προειδοποίηση κατά την εκκίνηση). Η τιμή του παραδείγματος `change-me` απορρίπτεται. |
| `MINER_PASSWORD_FILE` | καμία | Διαβάζει το `MINER_PASSWORD` από αρχείο, όπως ένα Docker secret. Το ένα ή το άλλο, όχι και τα δύο. |
| `MINER_PUBLIC_URL` | καμία | Μόνο πίσω από HTTPS reverse proxy (Caddy, nginx, Traefik, Cloudflare Tunnel…): η διεύθυνση `https://` του πίνακα ελέγχου, χωρίς διαδρομή, όπως `https://miner.example.com`. Ο proxy πρέπει να προωθεί τα `X-Forwarded-Proto`, `X-Forwarded-For` και τα websockets, κάτι που οι συνηθισμένοι proxies κάνουν από προεπιλογή, και η θύρα του container δεν πρέπει να είναι προσβάσιμη απευθείας. Τότε ο πίνακας ελέγχου απορρίπτει ό,τι δεν περνά από τον proxy μέσω HTTPS και κλειδώνει μια διεύθυνση για 30 δευτερόλεπτα μετά από 5 λάθος κωδικούς. Ο διακομιστής μεσολάβησης πρέπει να τρέχει στο ίδιο μηχάνημα ή στο τοπικό του δίκτυο: μια σύνδεση από δημόσια διεύθυνση απορρίπτεται. |
| `MINER_TRUSTED_HOPS` | `1` | Μόνο μαζί με το `MINER_PUBLIC_URL`: πόσοι proxies προσθέτουν καταχώριση στο `X-Forwarded-For`, από 1 έως 10. `2` με δύο proxies τον έναν πίσω από τον άλλον, όπως Cloudflare μπροστά από Traefik. |
| `MINER_PROXY_NETWORKS` | καμία | Μόνο με `MINER_PUBLIC_URL`: τα δίκτυα από τα οποία συνδέεται ο διακομιστής μεσολάβησης, χωρισμένα με κόμματα: μία διεύθυνση ή ένα δίκτυο όπως `192.168.1.0/24` ή `2001:db8:1::/64`. Μόλις οριστεί, ο διακομιστής μεσολάβησης γίνεται δεκτός μόνο από τη διεύθυνση loopback και από αυτά τα δίκτυα, όχι πια από όλο το ιδιωτικό τοπικό δίκτυο. |
| `MINER_VAULT_PASSPHRASE` | καμία | Μόνο για φάκελο δεδομένων που αντιγράφηκε από την εφαρμογή επιφάνειας εργασίας με κωδικό εφαρμογής: τον ξεκλειδώνει κατά την εκκίνηση. Ένας server που στήνεται από το μηδέν δεν τη χρειάζεται ποτέ. |
| `MINER_VAULT_PASSPHRASE_FILE` | καμία | Διαβάζει το `MINER_VAULT_PASSPHRASE` από αρχείο. Το ένα ή το άλλο, όχι και τα δύο. |
| `DATA_DIR` | `/data` στην εικόνα, αλλιώς `data` στον κατάλογο εργασίας | Βάση δεδομένων, αρχείο κλειδιού και αρχεία καταγραφής. |
| `LOG_DIR` | `$DATA_DIR/logs` | Αρχεία καταγραφής: ένα την ημέρα, κρατιούνται τα τελευταία 14. |
| `HOST` / `PORT` | `0.0.0.0` / `8080` | Διεύθυνση ακρόασης: μια διεύθυνση IP και μια θύρα από 1 έως 65535. |
| `RUST_LOG` | `info,hyper=warn,reqwest=warn` | Επίπεδο καταγραφής. |

Ο server διαβάζει και ελέγχει τις μεταβλητές μία φορά, κατά την εκκίνηση. Μια μη έγκυρη τιμή σταματά τον server με μήνυμα, αντί να περάσει σιωπηλά σε εναλλακτική τιμή.

Πίσω από reverse proxy, ορίστε το `MINER_PUBLIC_URL`: χωρίς αυτό, το πρώτο αίτημα που φτάνει μέσω proxy γράφει μια προειδοποίηση στα αρχεία καταγραφής, γιατί οι προσπάθειες σύνδεσης μετρώνται τότε στη διεύθυνση του proxy και οι λάθος κωδικοί ενός επισκέπτη θα κλείδωναν έξω όλους. Η ζωντανή σύνδεση στέλνει ένα ping κάθε 30 δευτερόλεπτα, ώστε ένας proxy να μην την κλείνει όταν δεν συμβαίνει τίποτα. Όταν το Twitch ή το δίκτυο αποτυγχάνει, ο server απαντά `424`, ποτέ `502` ή `504`: πίσω από το Cloudflare, βλέπετε το πραγματικό σφάλμα αντί για τη σελίδα του Cloudflare.

### <a name="systemd"></a>Χωρίς Docker (systemd)

Σε Linux server χωρίς Docker, η έκδοση περιλαμβάνει τον server και ως ένα μόνο αρχείο, με
τον πίνακα ελέγχου μέσα: `twitch-miner-server_<έκδοση>_linux_x64` ή
`twitch-miner-server_<έκδοση>_linux_arm64`. Είναι το ίδιο πρόγραμμα που τρέχει η εικόνα
Docker, στατικά συνδεδεμένο: τίποτα άλλο δεν χρειάζεται να εγκατασταθεί, εκτός από τα
πιστοποιητικά CA του συστήματος που διαβάζει για HTTPS (η εικόνα Docker τα αντιγράφει για
τον ίδιο λόγο). Δέχεται τις ίδιες μεταβλητές.

```bash
# ARM64: twitch-miner-server_<έκδοση>_linux_arm64
sudo install -m 755 twitch-miner-server_<έκδοση>_linux_x64 /usr/local/bin/twitch-miner
sudo install -m 600 /dev/null /etc/twitch-miner.env
```

Γράψτε τον δικό σας κωδικό, 12 χαρακτήρες ή περισσότερους, στο `/etc/twitch-miner.env`,
που μπορεί να διαβάσει μόνο ο root:

```ini
MINER_PASSWORD=change-me
```

Έπειτα την υπηρεσία, στο `/etc/systemd/system/twitch-miner.service`:

```ini
[Unit]
Description=Twitch Miner
Wants=network-online.target
After=network-online.target

[Service]
ExecStart=/usr/local/bin/twitch-miner
EnvironmentFile=/etc/twitch-miner.env
Environment=DATA_DIR=/var/lib/twitch-miner
DynamicUser=yes
StateDirectory=twitch-miner
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now twitch-miner
```

Το systemd δημιουργεί το `/var/lib/twitch-miner` για τα δεδομένα και τρέχει τον server με
δικό του χρήστη, ποτέ ως root. Ανοίξτε το `http://<διεύθυνση του server>:8080`· τα αρχεία
καταγραφής βρίσκονται στο `journalctl -u twitch-miner`.

Αυτό το αρχείο δεν ενημερώνεται μόνο του. Όταν ο πίνακας ελέγχου δείξει νέα έκδοση,
κατεβάστε το νέο αρχείο από την έκδοση, αντικαταστήστε το παλιό και κάντε επανεκκίνηση:

```bash
# ARM64: twitch-miner-server_<έκδοση>_linux_arm64
sudo install -m 755 twitch-miner-server_<έκδοση>_linux_x64 /usr/local/bin/twitch-miner
sudo systemctl restart twitch-miner
```

## <a name="how-it-works"></a>Πώς λειτουργεί

Κάθε 20 δευτερόλεπτα, κάθε λογαριασμός επιλέγει τα δύο κανάλια του: το καλύτερο ζωντανό κανάλι για την πρώτη καμπάνια της ουράς του και μετά τους streamers της λίστας πόντων του. Μια καμπάνια χωρίς ζωντανό κανάλι παραλείπεται υπέρ της επόμενης που έχει ένα («Κανένα κανάλι live» στην ουρά της)· τα ζωντανά κανάλια ελέγχονται ξανά κάθε 90 δευτερόλεπτα και ο λογαριασμός επιστρέφει σε αυτήν μόλις ένας από τους streamers του γίνει live.

Το Twitch πιστώνει **μία καμπάνια Drops** και **δύο κανάλια για πόντους** τη φορά ανά λογαριασμό. Από τον Οκτώβριο του 2026, ένα drop μπορεί να παραληφθεί μόνο όταν ο λογαριασμός εκδότη είναι συνδεδεμένος. Οι μη συνδεδεμένες καμπάνιες συνεχίζουν να προχωρούν και ο πίνακας ελέγχου δείχνει τον σύνδεσμο.

Αν η δική του πρόοδος του Twitch στην πρώτη καμπάνια δεν κινηθεί μετά από 30 λεπτά πραγματικής παρακολούθησης, δεν την πιστώνει: ο λογαριασμός τη βάζει στην άκρη, η επόμενη καμπάνια στη σειρά παίρνει τη θέση της, και γίνεται αυτόματα νέα προσπάθεια 6 ώρες αργότερα — νωρίτερα, αν εμφανιστεί πρόοδος πρώτα, αν και η καμπάνια που ξαναδοκιμάζεται μπορεί ακόμη να περιμένει πίσω από όποια εξορύσσεται εκείνη τη στιγμή. Οποιαδήποτε πρόοδος μηδενίζει αυτή την αναμονή, και αυτό ισχύει για κάθε είδος καμπάνιας (Drops, σήματα, αποστολές). Αν το Twitch πιστώσει αντ' αυτού μια άλλη καμπάνια της ίδιας κατηγορίας και αυτή ολοκληρωθεί ή παραληφθεί, η αναβολή αίρεται αμέσως αντί να περιμένει τις πλήρεις 6 ώρες. Η επανεκκίνηση της εφαρμογής ή του server ξεχνά κάθε καμπάνια που έχει μπει στην άκρη: μια κολλημένη καμπάνια απλώς παίρνει 30 φρέσκα λεπτά.

Η λίστα καμπανιών προέρχεται από το έργο [Twitch Drops API](https://drops.sunkwi.com) (ανανεώνεται κάθε 5 λεπτά), επειδή το Twitch την κρύβει από τον client τηλεόρασης.

## <a name="faq"></a>Συχνές ερωτήσεις

### Κίνδυνοι και Twitch

**Μπορεί να αποκλειστεί ο λογαριασμός μου;**\
Κανείς δεν μπορεί να εγγυηθεί ότι δεν θα συμβεί. Αυτό το έργο δεν σχετίζεται με το Twitch και η αυτοματοποίηση ενός λογαριασμού μπορεί να παραβιάζει τους όρους του ή τους κανόνες μιας καμπάνιας. Ο miner παρακολουθεί το πολύ δύο κανάλια ανά λογαριασμό, το όριο του Twitch, χωρίς να κατεβάζει κανένα βίντεο. Η απόφαση είναι δική σας.

**Παρακολουθείται πραγματικά το βίντεο;**\
Όχι, δεν κατεβαίνει κανένα βίντεο. Για τα Drops, κάθε 15 δευτερόλεπτα ο miner διαβάζει τη λίστα αναπαραγωγής του stream στη χαμηλότερη ποιότητα και ζητά μόνο την κεφαλίδα κάθε νέου τμήματος. Για τους πόντους, στέλνει κάθε λεπτό το σήμα «λεπτό παρακολούθησης» του Twitch. Κάθε κανάλι που παρακολουθείται δείχνει πόσα τμήματα ζητήθηκαν.

**Γιατί το πολύ δύο κανάλια;**\
Αυτό είναι το όριο του Twitch: πιστώνει μόνο δύο κανάλια που παρακολουθούνται ταυτόχρονα ανά λογαριασμό και μόνο μία καμπάνια Drops τη φορά. Στη λειτουργία **Drops και πόντοι**, το ένα κανάλι εξυπηρετεί την καμπάνια και το άλλο τους streamers σας. Η ρύθμιση «Ένα κανάλι», στις **Ρυθμίσεις λογαριασμού**, κάνει λιγότερο θόρυβο.

### Drops

**Μια καμπάνια δεν εξορύσσεται ή ένα drop δεν προχωρά.**\
Ανοίξτε τη σελίδα **Drops** του λογαριασμού. Στη «Σειρά εξόρυξης», κάθε καμπάνια σε αναμονή λέει γιατί: «Κανένα κανάλι live» ή «Αναμονή (μία καμπάνια τη φορά)». «Το Twitch δεν το μετράει — νέα προσπάθεια …» σημαίνει ότι 30 λεπτά πραγματικής παρακολούθησης δεν έφεραν πρόοδο από την πλευρά του Twitch: η καμπάνια μπαίνει στην άκρη και ξαναδοκιμάζεται αυτόματα μετά τον χρόνο που εμφανίζεται, ή νωρίτερα, αν εμφανιστεί πρόοδος πρώτα. Μια καμπάνια που δεν εμφανίζεται σε αυτή τη λίστα έχει αποκλειστεί: από το «Τι να εξορύσσεται, με σειρά», από τη ρύθμιση «Ποιες καμπάνιες», από έναν κανόνα στην καρτέλα **Εξαιρέσεις**, επειδή δεν προλαβαίνει να ολοκληρωθεί ή επειδή όλες οι ανταμοιβές που της μένουν απαιτούν συνδρομή. Μια ανταμοιβή που απαιτεί συνδρομή περιμένει να κάνετε ή να χαρίσετε μια συνδρομή κατά τη διάρκεια της καμπάνιας, σε ένα κανάλι της κατηγορίας (μια ήδη ενεργή συνδρομή, μια συνδρομή Prime ή μια ανανέωση δεν μετράνε), ένα σήμα που θέλει παρακολούθηση κάθε μέρα περιμένει την επόμενη μέρα, τίποτα δεν εξορύσσεται πριν ξεκινήσει η καμπάνια του και ένα drop που έρχεται μετά από άλλο περιμένει να ολοκληρωθεί το πρώτο. Στη λειτουργία **Μόνο πόντοι**, ο miner δεν επιλέγει καμία καμπάνια. Η «Εξόρυξη με προτεραιότητα», στις λεπτομέρειες μιας καμπάνιας, τη βάζει στην κορυφή· μια καμπάνια σε παράβλεψη μπορεί να επιστρέψει με την «Εξόρυξη ξανά», στην καρτέλα **Εξαιρέσεις**. Η καρτέλα **Καμπάνιες** δείχνει τους ίδιους λόγους στην ομάδα **Αποκλεισμένες**.

**Πρέπει να συνδέσω τον λογαριασμό εκδότη;**\
Για την παραλαβή, ναι: από τον Οκτώβριο του 2026, το Twitch επιτρέπει την παραλαβή ενός drop μόνο όταν ο λογαριασμός εκδότη είναι συνδεδεμένος. Από προεπιλογή, μια μη συνδεδεμένη καμπάνια συνεχίζει να προχωρά και η παραλαβή περιμένει τη σύνδεση. Το σήμα «Μη συνδεδεμένο» το επισημαίνει και η «Σύνδεση λογαριασμού εκδότη», στις λεπτομέρειες της καμπάνιας, ανοίγει τη σελίδα σύνδεσης. Για να εξορύσσετε μόνο συνδεδεμένες κατηγορίες, επιλέξτε «Μόνο κατηγορίες με συνδεδεμένο λογαριασμό εκδότη».

### Εγκατάσταση και δεδομένα

**Εφαρμογή επιφάνειας εργασίας ή Docker;**\
Η εφαρμογή επιφάνειας εργασίας εξορύσσει όσο ο υπολογιστής σας είναι ανοιχτός, με το εικονίδιό της στη γραμμή συστήματος, προαιρετικό κωδικό και ενημερώσεις με ένα κλικ. Το Docker εξορύσσει μέρα νύχτα σε ένα μηχάνημα που μένει πάντα ανοιχτό (VPS, NAS, Raspberry Pi)· το ανοίγετε σε browser, προστατευμένο με το `MINER_PASSWORD`. Το περιβάλλον είναι το ίδιο.

**Πού βρίσκονται τα δεδομένα μου;**\
Στον φάκελο δεδομένων: `~/.local/share/twitch-miner` σε Linux, `%APPDATA%\twitch-miner` σε Windows, `~/Library/Application Support/twitch-miner` σε macOS και ο τόμος `/data` με το Docker. Στην επιφάνεια εργασίας, οι **Ρυθμίσεις › Επιφάνεια εργασίας** τον ανοίγουν με ένα κλικ. Περιέχει το `miner.db` (λογαριασμοί, ρυθμίσεις, χρονικό), το `master.key` (το κλειδί των συνεδριών, όταν δεν έχει οριστεί κωδικός εφαρμογής) και τα αρχεία καταγραφής.

**Πώς κάνω ενημέρωση;**\
Η εφαρμογή επιφάνειας εργασίας ελέγχει για νέα έκδοση κατά την εκκίνηση και μετά κάθε ώρα (μπορείτε να το αλλάξετε από τις **Ρυθμίσεις › Σχετικά**) και μπορεί να σας ειδοποιήσει όταν βρει μία. Πατήστε το σήμα «Ενημέρωση» και μετά «Εγκατάσταση και επανεκκίνηση». Με το Docker, ο πίνακας ελέγχου σάς ειδοποιεί: εκτελέστε `docker compose pull` και μετά `docker compose up -d`. Χωρίς Docker, ο πίνακας ελέγχου σάς ειδοποιεί με τον ίδιο τρόπο: δείτε το [Χωρίς Docker](#systemd) για να αντικαταστήσετε το αρχείο και να επανεκκινήσετε την υπηρεσία. Κάθε νέα έκδοση δείχνει τις αλλαγές της στην εφαρμογή και στη σελίδα της στο GitHub.

**Ξέχασα τον κωδικό της εφαρμογής.**\
Δεν ανακτάται: αυτός κρυπτογραφεί τις συνεδρίες σας στο Twitch. Κλείστε την εφαρμογή, διαγράψτε τον φάκελο δεδομένων και μετά προσθέστε ξανά τους λογαριασμούς σας· οι ρυθμίσεις τους πρέπει να γίνουν από την αρχή. Με το Docker, ο κωδικός του πίνακα ελέγχου αλλάζει στο `MINER_PASSWORD` και μετά `docker compose up -d`.

### Πόντοι και προβλέψεις

**Πόσους πόντους την ώρα;**\
Εξαρτάται από το Twitch και από κάθε κανάλι. Ο miner κερδίζει ό,τι δίνει το Twitch σε έναν θεατή: πόντους χρόνου παρακολούθησης, μπόνους σεντούκια (περίπου ένα κάθε 15 λεπτά) και το μπόνους του σερί παρακολούθησης. Μια συνδρομή πολλαπλασιάζει τους πόντους, από ×1,2 έως ×2 ανάλογα με το επίπεδο, και με το «Πρώτα τα κανάλια με συνδρομή», ενεργό από προεπιλογή, αυτά τα κανάλια μπαίνουν πριν από την υπόλοιπη λίστα σας. Η Αρχική δείχνει τους πόντους που κερδήθηκαν και το Χρονικό κάθε κέρδος.

**Είναι ριψοκίνδυνα τα στοιχήματα;**\
Ναι, μπορείτε να χάσετε πόντους. Οι προβλέψεις είναι απενεργοποιημένες από προεπιλογή, για κάθε streamer χωριστά. Ορίζετε τη στρατηγική, πότε γίνεται το στοίχημα, το ποντάρισμα (5% του υπολοίπου από προεπιλογή, το πολύ 50.000 πόντοι), ένα ελάχιστο υπόλοιπο και, αν θέλετε, μια συνθήκη, όπως απόδοση τουλάχιστον 1,5. Κρατήστε το ποντάρισμα μικρό. Ένα ποντάρισμα κάτω από 10 πόντους δεν τοποθετείται ποτέ.

**Ένας streamer δεν παρακολουθείται.**\
Παρακολουθούνται μόνο οι streamers που είναι ενεργοποιημένοι και σε live, και μόνο σε ελεύθερο κανάλι: στη λειτουργία **Drops και πόντοι**, το ένα από τα δύο εξυπηρετεί την τρέχουσα καμπάνια· στη λειτουργία **Μόνο Drops**, δεν παρακολουθείται κανένας streamer· ένας λογαριασμός σε παύση δεν παρακολουθεί τίποτα. Οι θέσεις μοιράζονται με αυτή τη σειρά, που εμφανίζεται ως σήμα σε κάθε κανάλι που παρακολουθείται: «Το σερί κινδυνεύει», «Μπόνους σερί», «Συνδρομή» και μετά «Σειρά λίστας». Ανεβάστε τον streamer πιο ψηλά στη λίστα ή απενεργοποιήστε τα «Πρώτα τα σερί παρακολούθησης» και «Πρώτα τα κανάλια με συνδρομή».

## <a name="security"></a>Ασφάλεια

- Τα tokens σφραγίζονται με AES-256-GCM. Το κλειδί είναι είτε ένα τυχαίο `master.key` δίπλα στη βάση δεδομένων (προεπιλογή, δεν χρειάζεται να κάνετε τίποτα) είτε παράγεται από τον κωδικό εφαρμογής με Argon2id.
- Ο φάκελος δεδομένων και ο φάκελος αρχείων καταγραφής είναι ιδιωτικοί (`0700`): μόνο ο χρήστης που εκτελεί τον miner μπορεί να τους ανοίξει.
- Ο HTTP πίνακας ελέγχου ελέγχει τον κωδικό σε σταθερό χρόνο και χρησιμοποιεί cookies HttpOnly, SameSite=Strict (`Secure`, με το πρόθεμα `__Host-`, πίσω από HTTPS). Ο server κρατά μόνο ένα SHA-256 κάθε συνεδρίας. Τερματίζει μια συνεδρία μετά από 30 ημέρες ή κατά την αποσύνδεση. Ελέγχει τη συνεδρία πριν διαβάσει οποιοδήποτε σώμα αιτήματος και περιορίζει τα σώματα στα 256 KiB.
- Μετά από 5 συνεχόμενους λάθος κωδικούς από μία διεύθυνση IP (φόρμα σύνδεσης ή bearer), η διεύθυνση αυτή περιμένει 30 δευτερόλεπτα. Ο server απαντά `429` με `Retry-After` χωρίς να κοιτάξει τον κωδικό. Επιπλέον, η απάντηση σε κάθε λάθος κωδικό καθυστερεί μισό δευτερόλεπτο. Πέρα από 30 λάθος κωδικούς σε ένα λεπτό από την ίδια διεύθυνση σύνδεσης, μαζί και έναν κοινόχρηστο διακομιστή μεσολάβησης, η διεύθυνση αυτή παίρνει μία προσπάθεια κάθε 2 δευτερόλεπτα: η μαντεψιά επιβραδύνεται και κανείς δεν κλειδώνεται έξω.
- Εκτός του δικτύου σας, βάλτε τον πίνακα ελέγχου πίσω από HTTPS reverse proxy με το `MINER_PUBLIC_URL` (δείτε [Docker](#docker)).
- Ο miner επικοινωνεί μόνο με τα `twitch.tv`, `ttvnw.net`, `jtvnw.net`, `twitchcdn.net`, `drops.sunkwi.com` και τους προορισμούς ειδοποιήσεων που ρυθμίζετε. Η εφαρμογή (επιφάνειας εργασίας και Docker) ελέγχει για νέες εκδόσεις στο `github.com` και η εφαρμογή επιφάνειας εργασίας τις κατεβάζει από τα GitHub releases του έργου. Είναι υπογεγραμμένες: εγκαθίσταται μόνο η έκδοση που εμφανίζεται.

## <a name="build"></a>Μεταγλώττιση από τον πηγαίο κώδικα

**Προαπαιτούμενα:** Rust, Node.js και οι [προαπαιτήσεις του Tauri](https://v2.tauri.app/start/prerequisites/) για το σύστημά σας.

```bash
npm ci
npm run build          # πίνακας ελέγχου
cargo build --release -p miner-server   # server: target/release/twitch-miner
npm run bundle:linux   # πακέτα επιφάνειας εργασίας (απαιτούνται οι εξαρτήσεις Linux του Tauri)
```

Έλεγχοι κώδικα:

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
npm run verify         # prettier, oxlint (με επίγνωση τύπων), svelte-check και τον έλεγχο i18n του inlang
```

Οι τύποι TypeScript του περιβάλλοντος παράγονται από τους τύπους Rust με το [ts-rs](https://github.com/Aleph-Alpha/ts-rs) στο `ui/src/lib/bindings`. Μετά από αλλαγή σε τύπο που βλέπει το περιβάλλον, εκτελέστε `npm run bindings`.
